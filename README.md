# 音频停顿删除工具

一个专业的音频处理工具,用于自动检测和删除音频文件中的静音/停顿片段。基于高性能音频处理库开发,提供精确的音频分析和处理功能。

## 功能特点

- 专业的图形界面,美观易用
- 高精度波形显示,实时预览音频
- 精确的静音检测算法
  - 音量阈值:精确调节静音判定的音量大小
  - 最小持续时间:精确控制静音片段的最短时长
- 支持多种音频格式(WAV, MP3等)
- 自定义导出选项
  - 可选择导出位置和文件名
  - 自动添加时间戳,方便版本管理
- 专业级音频处理引擎
  - 高质量音频重采样
  - 精确的音频分析算法
  - 无损音频处理

## 使用方法

1. 运行程序,点击"选择文件"按钮选择要处理的音频文件
2. 在波形显示区域可以直观查看音频内容
3. 调整参数(可选):
   - 音量阈值:数值越小,越容易判定为静音
   - 最小持续时间:单位为秒,低于此时长的静音片段将被保留
4. 点击"处理"按钮开始处理音频
5. 处理完成后,点击"导出"按钮选择保存位置并导出处理后的音频文件

## 技术说明

- 使用Python开发
- 核心依赖:
  - PySide6: 专业级GUI框架
  - scipy: 高性能信号处理
  - numpy: 数值计算
  - soundfile: 专业音频处理
- 采用专业音频处理算法,保证处理质量

## 系统要求

- Windows 10及以上系统
- 4GB及以上内存
- 建议使用SSD硬盘以获得更好的处理性能

## 注意事项

- 首次使用建议先用小片段测试参数效果
- 处理大文件时会进行完整的音频分析,可能需要一定时间
- 导出文件默认添加处理时间戳,方便区分不同版本
- 程序会自动保存上次使用的参数设置
